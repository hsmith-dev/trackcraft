# Security policy

TrackCraft will hold teams' plans, discussions and documents, and from milestone M4 it runs as a
network server. Please report vulnerabilities privately through GitHub's **Report a
vulnerability** button on this repository's Security tab, not in public issues.

Include what you found, how to reproduce it, and what an attacker gains. We aim to acknowledge
reports within a week.

In scope: anything that crashes the app or corrupts a workspace from crafted input (`.track`
files, JQL, ADF documents, MCP/CLI/REST parameters), and, once the server exists, authentication,
authorisation and data-isolation bugs.
