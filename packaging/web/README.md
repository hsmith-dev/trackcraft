# Hosting TrackCraft for the web

`cargo xtask web` builds a static site into `dist/web` (building and limits: `docs/web.md`):

| File | What it is |
|---|---|
| `index.html` | The page. It loads everything through relative URLs. |
| `trackcraft-web-<hash>.js` | wasm-bindgen glue (generated by trunk, ES module) |
| `trackcraft-web-<hash>_bg.wasm` | The app |
| `_headers`, `.htaccess` | Sample header rules for Netlify/Cloudflare Pages and Apache (copied from here) |

`packaging/web/package.sh` zips the same site (plus this file as `HOSTING.md` and the licences)
as `trackcraft-web-<version>.zip`, the release asset. There is no server-side code. Serve the folder with `trackcraft-server serve --web dist/web`
(next to the API, same origin) or upload its contents anywhere that serves static files.

## Any path works

All URLs in `index.html` are relative (`public_url = "./"` in `apps/trackcraft-web/Trunk.toml`),
so the site works at a domain root, under a prefix and from a CDN bucket. Asset names carry a
content hash, so they can be cached forever; only `index.html` needs revalidation.

## Required server settings

- **MIME type:** serve `.wasm` as `application/wasm` (browsers refuse to stream-compile it
  otherwise) and `.js` as `text/javascript`. `trackcraft-server --web` does both.
- **Compression:** turn on gzip or Brotli for `.wasm`, `.js` and `.html` on a reverse proxy;
  `trackcraft-server` sends files uncompressed.
- **Caching:** `Cache-Control: public, max-age=31536000, immutable` on the hashed `.wasm` and
  `.js` files, `no-cache` on `index.html` (`trackcraft-server --web` does this).
- **HTTPS:** WebGPU only works in a secure context (`https://` or `http://localhost`); elsewhere
  the app falls back to WebGL2.
- **No isolation headers needed:** no `SharedArrayBuffer`, so no COOP/COEP.

nginx example:

```nginx
location /trackcraft/ {
    types { application/wasm wasm; text/javascript js; text/html html; }
    gzip on;
    gzip_types application/wasm text/javascript text/html;
    location ~* \.(wasm|js)$ { add_header Cache-Control "public, max-age=31536000, immutable"; }
    location ~* index\.html$ { add_header Cache-Control "no-cache"; }
}
```

## URL flags

| Flag | Effect |
|---|---|
| *(none)* | The workspace kept in this browser, else the sample; WebGPU if available, else WebGL2 |
| `?sample` | Open the sample workspace (the kept one stays stored until something changes) |
| `?webgl` | Force the WebGL2 backend |
